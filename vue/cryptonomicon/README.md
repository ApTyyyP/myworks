# cryptonomicon

## Project setup
Use Node.js 24.19.0 (see `.nvmrc`). Copy `.env.example` to `.env` and set
`VUE_APP_CRYPTOCOMPARE_KEY` before starting or building the app.

```
npm ci
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

### Customize configuration
The app uses Vite. See [Configuration Reference](https://vite.dev/config/).
Deploy the generated `dist` directory as a static site.

### Preview the production build
```
npm run preview
```

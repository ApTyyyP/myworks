# vue3-course

## Project setup
Requires Node.js 24.19.0 or later in the Node.js 24 LTS line (see `.nvmrc`).

```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Preview the production build
```
npm run preview
```

The project uses [Vite](https://vite.dev/guide/). `npm run dev` is also available
as an alias for the development server. Build output is written to `dist`.
Production hosting must serve `index.html` for Vue Router history routes.
